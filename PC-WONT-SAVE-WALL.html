If key is wrong / expired / paused

  • Send THIS PC’s Machine ID to owner
  • Ask: new 1-year key for this ID
  • About → Enter / Renew 1-Year Key
  • Paste key → retest save

Reinstall will NOT fix a wrong key.

3Open data folder

Win + R → %APPDATA%\CafeDesk → Enter

Tick files you see

  • settings.json
  • settings.json.bak
  • settings.json.corrupt
  • sales.sqlite3

Damaged settings?

  • App offers restore .bak → click Yes
  • No .bak → rename settings.json to settings.json.broken
  • Copy .bak → settings.json
  • Restart app → retest

4Save still fails? Tick one path

“Could not save …”

  • Disk C: not full
  • CafeDesk folder not read-only
  • Logged-in user can Write
  • Retry save in app

PIN / lock issues

  • Wait 60s after 5 wrong PINs
  • Unlock idle lock (5 min) with PIN
  • Save immediately after unlock

Sales missing only

  • Check Sales reports on THIS PC
  • Confirm “Recorded in sales history”
  • Import/sync from other PCs

Only now reinstall app

  • App broken / won’t open
  • Steps 2–4 didn’t help
  • Then: new key for THIS Machine ID
  • Then: Import Shop Pack / prices

5Quick tree

Won’t save ├─ “another computer” / expired / paused → NEW key for this Machine ID ├─ “Settings file damaged” → restore settings.json.bak ├─ “Could not save …” → disk / permissions / account ├─ Sales only → reports + sync other PCs └─ App won’t open → reinstall, then re-activate + re-import

Never

  • Copy license.json or a key from another PC
  • Delete the whole CafeDesk folder (sales live there)
  • Reinstall expecting it to change the Machine ID
  • Skip backup before updating other PCs
