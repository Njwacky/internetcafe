Save and reopen work

The desktop app saves a CV or picture sheet as a project file, including copies of its photos. It can be reopened later or moved to another computer.

This phone preview keeps the demo draft in memory only. It does not create a desktop project file.

Optional recovery

In the desktop app, you can opt in to a local recovery copy approximately every 60 seconds. A staff member can restore it after restarting.

Desktop project and recovery files contain text and photos and are not encrypted. Get the customer’s permission and keep files secure.

How it works

PREVIEW

1. Create your CV or picture sheet.

2. Choose Save project to keep working later.

3. Choose Open project to restore it.

4. Optionally enable local recovery while working.

The real project file includes its photos. Saved projects stay where you choose; they are not automatically uploaded anywhere.
