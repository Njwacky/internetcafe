“This PC won’t save” checklist

Use when one computer in the shop misbehaves and the others are fine — won’t save the key, PIN, business settings, prices, or sales. Tick each box as you go. About 10–15 minutes.

Station: ______________ Date: __________ Staff: ________ Time: 10–15 min

!Before you touch anything

Do

  • Write the exact words on screen (or photograph them)
  • Note the Station Name (e.g. Desk 2)
  • Note if hardware was changed or repaired
  • Keep the shop USB / backup nearby

Don’t

  • Don’t uninstall yet
  • Don’t copy license.json from another PC
  • Don’t delete the whole CafeDesk folder
  • Don’t guess the error — copy it word for word
Why one PC can differ: every install has its own Machine ID and its own local settings folder. A key or password from PC #1 will not unlock or configure PC #3.

  • Prices — disappear after restart

2Read the Machine ID (always)

Open About & contact → find Machine ID (CD-XXXX-XXXX-XXXX) → copy it into your notes. Check the licence card.

CD-____-____-____  ·  this PC’s Machine ID
What you see on the licence card What it means What to do
Active · days remaining shown Licence is fine — problem is elsewhere (settings/save) Go to Step 3
Activation screen at startup / “needs a 1-year activation key” This PC is not licensed (new PC, wiped install, or expired) Send this Machine ID to the owner for a key
“belongs to another computer” Wrong key — made for a different machine Get a new key for this Machine ID — reinstall will not help
“license expired on …” Renewal needed New 1-year key for the same Machine ID
“license has been paused” Owner must approve this Machine ID again Contact owner / request approval
This activation key belongs to another computer (CD-…). This computer’s Machine ID is CD-…. Please request a new key from the owner.
Hardware change = new Machine ID. Motherboard or major repair changes the ID. The old key will never work on the new hardware. A key for the new ID is required — not a reinstall.

If the key is wrong / expired / paused

  • Write down this PC’s Machine ID
  • Send that ID to the owner and ask for a new 1-year key for this Machine ID
  • About & contact → Enter / Renew 1-Year Key
  • Paste the key → retest the save

3Open this PC’s data folder

On Windows:

Win + R  →  %APPDATA%\CafeDesk  →  Enter

Tick files you see

  • settings.json — name, icon, PIN, station, prices
  • settings.json.bak — automatic good backup
  • settings.json.corrupt — damaged file quarantined
  • sales.sqlite3 — sales history
  • license.json — licence for this PC only

Portable USB mode?

  • Settings may live in CafeDeskData next to CafeDesk.exe
  • Check both locations if unsure
  • Write down which folder you used

4Match what you see to a fix

A · Settings damaged / staff access locked

Settings file is damaged or unreadable. Staff access is locked until an administrator restores settings.json.bak or removes the damaged file.
  • If the app offers restore from settings.json.bak → choose Yes
  • Damaged file is kept as settings.json.corrupt (safe)
  • Try the save again
  • No prompt / no .bak → close app → rename settings.json → settings.json.broken
  • Copy settings.json.bak → settings.json if present → start app → retest
Do not delete the whole folder — sales live there. Restoring .bak may reset some recent settings.

B · “Could not save …” (business / multi-PC / prices)

Could not save business name · Could not save settings · Export failed · Import failed
  • Close Café Desk
  • Confirm the drive with %APPDATA% is not full
  • CafeDesk folder → Properties → Security → user has Modify / Write
  • Use the Windows account that normally runs the shop app
  • Reopen and save again
  • Note whether every setting fails or only one screen

C · Key / PIN “won’t save” but folder looks healthy

  • Licence path → Step 2 (wrong / expired / paused key)
  • 5 wrong PINs → staff entry locks for 60 seconds — wait, use correct PIN
  • Idle lock → staff locks after ~5 minutes without mouse/keyboard — unlock with PIN and save immediately
  • Wrong-PC habit → settings on PC A do not appear on PC B unless you Import Shop Pack or sync

D · Only sales are missing

  • Sales live in sales.sqlite3 in the same data folder, per computer user
  • Confirm the sale was recorded: “Recorded in sales history”
  • Check Sales reports on this PC (station filter if present)
  • If the sale exists on another PC → Import Other PC File, Sync Shared LAN Folder, or Sync via Supabase
  • Don’t re-type sales on the broken PC

5Only now consider reinstall

Reinstall if

  • The app won’t start at all, or install files are broken
  • Steps 2–4 didn’t explain the problem

Reinstall does NOT

  • Change the Machine ID
  • Transfer a licence from another PC
  • Restore lost settings / prices / sales by itself

After any reinstall you still need

  • Correct activation key for this PC’s Machine ID
  • Re-enter or Import Shop Pack / Pull Prices from Cloud
  • PIN re-set if settings were wiped

6What to collect before asking for help

Send all of the following in one message.

1 · Station name of the bad PC
2 · Machine ID (CD-…)
3 · Exact error text / photo
4 · Hardware replaced or repaired? Y / N
5 · Fails: key / PIN / settings / prices / sales
6 · Files in %APPDATA%\CafeDesk (names)
7 · .corrupt or .bak present? Y / N
8 · App version (About & contact)

→Quick decision tree

One PC won’t save │ ├─ Error mentions “another computer” / activation / expired / paused │ → Machine ID or key problem │ → Get NEW key for THIS PC’s Machine ID (reinstall will not help) │ ├─ “Settings file damaged” / staff locked fail-closed │ → Restore settings.json.bak (or repair that one file) │ → Never delete the whole CafeDesk folder │ ├─ “Could not save …” with no licence wording │ → Disk full? Folder read-only? Wrong Windows account? │ → Fix permissions / free space on THAT PC only │ ├─ Sales missing only │ → Check Sales reports + sync/import from other PCs │ └─ App broken / won’t open at all → Reinstall app, THEN re-activate with key for this Machine ID and re-import Shop Pack / prices

★Shop-wide habit (before any update)

Do these on all shop PCs so one bad machine never strands you.

Prices & settings

  • Business settings → Export / Import Shop Pack (`.cafeshop.json`)
  • Keep a copy on USB and one other PC
  • Or use Push / Pull Prices via Cloud

Folder backup

  • Close Café Desk
  • Copy each PC’s %APPDATA%\CafeDesk folder to backup
  • That one folder restores PIN, prices, logo and sales

Sales sync

  • LAN folder / Import Other PC File / Supabase
  • No single PC should be the only copy

Update order

  • Backup all 5 PCs first
  • Update one pilot PC
  • Confirm it works → update the rest
