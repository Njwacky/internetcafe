Install

Three steps, one minute

You need a 64-bit Windows 10 or 11 PC and an activation key from Café Desk.

Step 01

Download the installer

Tap Download installer. Your browser saves CafeDesk-Setup.exe in Downloads.

Go to downloads
Step 02

Allow it to run

If Windows SmartScreen appears, choose More info → Run anyway. Compare the SHA-256 above to be sure the file is genuine.

Step 03

Activate this computer

On first launch Café Desk shows a Machine ID like CD-1A2B-3C4D-5E6F. Send it to the owner and paste the key back — or tap Check online approval.

FAQ

Questions before you install

Do I need internet or Python installed?
No. Café Desk is a finished Windows application — there is nothing else to install. An internet connection is only used for activation, cloud price sync and app updates. Every document tool works fully offline.
Is the app free?
The download is free. Using the workspace needs a paid activation key — one per computer, valid for one year. The PDF password remover is a separate paid add-on. Ask your shop owner for a key, or log in to issue one.
Why does Windows warn me before running it?
SmartScreen flags any new installer it has not seen many times yet. Choose More info → Run anyway. You can confirm the file with the SHA-256 checksum published above and on the GitHub release page.
Can I run it from a flash drive on several PCs?
Yes. Download the portable ZIP, unzip the CafeDesk folder onto the drive and run CafeDesk.exe from there. Each computer still needs its own activation key.
Are customer documents uploaded anywhere?
No. PDFs, CVs, photos, scans, receipts and forms are processed on the PC and never leave it. Only anonymous usage counts — which tool was opened and how often — plus the shop and city name reach the owner dashboard. Never filenames, documents or customer details.
How do updates work?
Café Desk tells you inside the app when a newer version is published and downloads it over the internet. You can also re-run the installer from this page at any time — your prices and settings are kept.
Will it run on 32-bit or older Windows?
No. Café Desk targets 64-bit Windows 10 and 11. Windows 7, 8, 8.1 and 32-bit machines are not supported.
